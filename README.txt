Instructions to Run
-------------------
1. Download or clone the project files.
2. Keep all files and folders in their correct locations.
3. Open the project folder in Visual Studio Code.
4. Run "index.html" using the Live Server extension or another local web server.
5. Click the dictionary application button to open "app.html".
6. Enter an English word and click Search to view its definition.

(An internet connection is required because definitions come from the API.)


Features
--------
- Search for an English word (button or Enter key)
- Definitions, parts of speech
- Phonetic spelling and audio pronunciation when available
- Example sentences and synonyms when provided by the API
- Loading indicator
- Friendly messages for empty input, word not found, API errors, and network failures
- Responsive layout for mobile, tablet, and desktop
